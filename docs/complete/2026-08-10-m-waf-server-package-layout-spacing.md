# 보호 서버 패키지 화면 간격과 긴 문자열 개선 완료

## 변경 내용

- Agent 현재 버전과 Manager 제공 버전을 줄바꿈 없이 한 줄 식별자로 표시하고, 공간이 부족할 때는 해당 값 안에서 가로로 확인할 수 있게 했다.
- Agent 정보와 작업 영역의 너비를 균등하게 배치하고 작업 카드가 내용보다 불필요하게 길어지지 않도록 조정했다.
- 화면 제목, 단계 구분 문구, 제목, 설명 사이의 세로 간격과 줄 높이를 통일했다.
- 현재 해야 할 일과 패키지 알림 안에서 제목과 본문이 붙어 보이지 않도록 간격을 추가했다.
- 모듈 설치 선택 화면의 `권장` 배지를 본문 흐름에 배치해 제목과 겹치지 않도록 했다.
- 긴 설치 파일 식별자가 `필요 정보 복사` 버튼을 밀어 문구가 세로로 깨지지 않도록 버튼의 최소 표시 폭을 보존했다.
- 지원 운영체제 안내 문구를 `Ubuntu 24.04 또는 Debian 12`로 읽기 쉽게 정리했다.

## 호환성

- 표시 스타일과 안내 문구만 변경했으며 설치 판단, 패키지 예약, 권한, Agent API, DB 구조는 변경하지 않았다.
- 좁은 화면에서는 기존처럼 한 열로 전환되고, 긴 버전과 설치 파일 식별자는 카드 밖으로 넘치지 않는다.

## 검증

- 긴 Agent 버전에 적용되는 전용 표시 클래스 검증 코드를 추가했다.
- Go 소스 형식과 `git diff --check`를 확인했다.
- 저장소 지침에 따라 전체 Go 테스트, 프론트엔드 빌드, 브라우저 실행, DB 작업은 수행하지 않았다.
