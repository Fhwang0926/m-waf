# M-WAF 기업 상세 조회

## 완료 범위

- 시스템 관리자 기업 목록에서 기업명과 `상세` 작업으로 기업 상세 화면에 진입할 수 있게 했다.
- 기업 상세 화면에 운영 상태, 등록일, 연결 데이터와 토큰 이력을 요약했다.
- 소속 사용자, 보호 서버, 기업 정책, 서버 그룹을 기업 범위로 조회해 각 상세 화면과 연결했다.
- 운영 종료 기업은 과거 이력을 계속 조회하되 사용자 수정과 신규 등록 작업을 읽기 전용으로 제한했다.
- 기업 상세에서 사용자 추가 화면으로 이동하면 해당 기업이 기본 선택되게 했다.

## 권한과 호환성

- `GET /enterprises/{id}`는 기존 기업 관리와 동일하게 시스템 관리자에게만 허용한다.
- 기존 세션, CSRF, 역할 검사, 기업 목록 URL과 Agent/Admin API 형식은 변경하지 않았다.
- DB 스키마와 저장 데이터는 변경하지 않고 기존 조회를 조합했다.

## 확인 범위

- Go 포맷과 정적 diff 검사를 수행한다.
- 현재 실행 중인 개발 Manager의 자동 재빌드 결과와 보호된 상세 URL 응답을 확인한다.
- 저장소 지침에 따라 프론트엔드 빌드, 자동 테스트, DB migration 적용·초기화·reset은 수행하지 않는다.
