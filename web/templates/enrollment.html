커스텀 Apache/Nginx 연결 명령

기존 ModSecurity Connector가 이미 로드된 서버에서만 사용합니다.

sudo sh /tmp/mwaf-install.sh \
  --manager {{.AgentURL}} \
  --ca /tmp/mwaf-manager-ca.crt \
  --install-token-stdin \
  --module-install manual \
  --integration external \
  --webserver apache \
  --webserver-bin /opt/hosting/apache/bin/apachectl \
  --integration-config /opt/hosting/apache/conf/extra/mwaf.conf \
  --reload

Nginx는 --webserver nginx와 실제 바이너리·전용 conf 경로를 지정하세요.
