# M-WAF 설치 대상 기업 선택 레이아웃 개선 완료

## 작업 목적

시스템 관리자의 서버 설치 화면에서 기업 선택 버튼이 다음 줄로 떨어지고, 선택 영역 하단에 불필요한 여백이 생기는 문제를 정리했다.

## 반영 내용

- 설치 대상 기업 선택 영역에 전용 스타일 클래스를 추가했다.
- 일반 화면에서 기업 선택 필드와 `선택` 버튼을 한 줄에 배치했다.
- 선택 영역의 패딩을 통일하고 다음 설치 환경 패널과 16px 간격을 적용했다.
- 760px 이하에서는 필드와 버튼을 다시 세로로 배치하고 버튼을 전체 너비로 표시한다.
- 기존 GET URL, 기업 선택값 및 권한 조건은 변경하지 않았다.

## 확인 범위

- CSS 중괄호와 Go 템플릿 구문 구분자 균형을 정적으로 확인했다.
- `git diff --check`로 공백 및 패치 형식을 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- Manager 재빌드·재시작 및 브라우저 확인은 수행하지 않았다.
- DB 조회·변경, migration, init, reset은 수행하지 않았다.
