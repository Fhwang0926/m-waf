# 서버 설치 진행 단계 상단 띠 수정

## 완료 내용

- 공통 목록 항목 간격 규칙이 서버 설치 진행 단계의 두 번째·세 번째 항목에 적용되던 문제를 수정했습니다.
- 진행 단계 항목의 바깥 여백을 0으로 고정해 상단에 노출되던 불필요한 색상 띠를 제거했습니다.
- 단계 사이에는 기존의 1px 구분선만 유지됩니다.

## 영향 범위

- 서버 상세의 `패키지` 탭에 표시되는 설치 진행 단계 UI만 변경됩니다.
- API, 데이터베이스, 설치 처리 로직은 변경하지 않았습니다.

## 확인

- 변경 파일의 공백 오류를 확인했습니다.
- 지침에 따라 프론트엔드 빌드와 테스트는 수행하지 않았습니다.
