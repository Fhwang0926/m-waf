# M-WAF 기업 상세 탭 분리 완료

## 작업 목적

시스템 관리자용 기업 상세 화면에서 기업 정보, 사용자, 서버, 정책, 그룹과 위험 작업이 한 페이지에 모두 노출되고 관련 목록도 한 요청에서 함께 조회되던 구성을 역할별 탭으로 분리했다.

## 반영 내용

- 기존 `GET /enterprises/{id}` 경로를 유지하고 `tab` 쿼리로 `개요`, `사용자`, `보호 서버`, `보호 정책`, `서버 그룹`, `상태 관리`를 구분했다.
- 알 수 없는 탭 값은 개요로 안전하게 처리하며 각 탭에 `aria-current`를 적용했다.
- 개요에서는 기업 연결 요약과 기업 정보만 표시한다.
- 사용자 관리 버튼을 페이지 공통 헤더에서 사용자 탭 내부로 이동했다.
- 서버, 정책과 그룹은 시스템 관리 관점의 기존 읽기 전용 표시를 유지했다.
- 운영 종료와 삭제는 마지막 상태 관리 탭으로 이동하고 오류 또는 운영 종료 후에도 해당 탭으로 복귀하게 했다.
- 개요와 사용자 탭은 사용자 목록만, 서버·정책·그룹 탭은 각 탭에 필요한 목록만 조회하도록 변경했다.
- 기존 사용자 관리 경로, 기업 삭제 API, CSRF, 시스템 관리자 권한과 기업 데이터 의미는 변경하지 않았다.
- 기존 공통 탭 스타일을 재사용하고 탭 패널의 중복 상단 여백만 정리했다.

## 정적 확인 범위

- 지원 탭 allowlist와 알 수 없는 탭의 개요 fallback 검증을 추가했다.
- 선택한 탭의 섹션만 렌더링되고 개요 요약이 다른 탭에 노출되지 않는 템플릿 검증을 추가했다.
- 실행 중인 Manager의 인증된 화면에서 기본 개요와 `보호 정책` 탭이 각각 해당 내용만 렌더링하는 것을 확인했다.
- Go 포맷과 `git diff --check`를 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 자동 테스트와 프론트엔드 빌드는 수행하지 않았다.
- 모바일·태블릿 반응형 화면은 별도로 실행하지 않았다.
- DB 변경, init, reset 및 스키마 마이그레이션은 수행하지 않았다.
