# M-WAF CRS Setup 인벤토리 레이아웃 개선 완료

## 작업 목적

CRS Setup 목록에서 긴 설정 키와 원본 값이 상태 및 위치 열과 함께 지나치게 압축되어 글자가 세로로 잘게 나뉘는 문제를 개선했다.

## 반영 내용

- `선언`과 `시스템 정책` 열을 `상태` 열로 통합해 5열 표를 4열로 줄였다.
- 원본 값은 기본 2줄 요약으로 표시하고 행 안에서 전체 원문을 펼쳐 확인할 수 있게 했다.
- Setup key, 상태, 위치 열에 전용 너비를 적용했다.
- 표의 최소 너비를 지정해 좁은 화면에서 문자를 억지로 잘게 나누지 않고 표 영역만 가로 스크롤되게 했다.
- 위치 값은 줄바꿈하지 않도록 정리했다.
- 템플릿 검증에 요약형 표와 원본 값 펼침 구조를 확인하는 항목을 추가했다.

## 호환성

- CRS Setup 데이터, 검색, 시스템 정책 연결 및 API는 변경하지 않았다.
- JavaScript 없이 HTML `details` 기본 동작으로 원문을 확인할 수 있다.
- 기존 공용 파일·Rule 인벤토리 표 스타일은 변경하지 않았다.

## 확인 범위

- Go 템플릿 구조와 CSS 중괄호 균형을 정적으로 확인했다.
- `git diff --check`로 공백 및 패치 형식을 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 현재 실행 중인 Manager의 재빌드·재시작 및 브라우저 확인은 수행하지 않았다.
- DB 조회·변경, migration, init, reset은 수행하지 않았다.
