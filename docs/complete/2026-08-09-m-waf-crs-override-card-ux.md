# 고급 CRS 설정 상속·직접 설정 UX 개선

## 작업 목적

상속 중인 CRS 설정도 비활성 입력란으로 모두 노출되어 편집 가능 여부가 불분명하고, 상속 상태·적용값·CRS 기본값이 한 문장에 반복되던 화면을 단순화했다.

## 반영 내용

- 상속 중인 항목은 입력 UI를 숨기고 `현재 정책 상속` 또는 `CRS 기본값 상속`과 실제 적용값만 표시한다.
- `직접 설정`을 선택한 항목만 편집 UI를 펼치고 카드의 활성 상태를 구분한다.
- 직접 설정을 해제하면 기존 동작처럼 상속값을 복원하고 상속용 hidden 필드만 전송한다.
- 직접 설정 중에는 편집 UI 아래에서 CRS 기본값을 비교할 수 있다.
- 허용 HTTP 버전은 원시 문자열 textarea 대신 HTTP/1.0, HTTP/1.1, HTTP/2, HTTP/2.0, HTTP/3, HTTP/3.0 선택 항목과 기타 버전 입력으로 변경했다.
- 허용 HTTP Method와 Content-Type의 기존 선택형 편집 방식은 유지했다.
- 편집값을 변경하면 카드의 적용값 요약도 즉시 갱신한다.
- 서버에 전송되는 `setup.*`, `override.*` 필드와 CRS 값 형식, 검증 API 및 오류 자동 이동 구조는 변경하지 않았다.

## 확인 내용

- 관련 템플릿, JavaScript, CSS의 `git diff --check`를 확인했다.
- 현재 개발 Manager가 변경된 템플릿을 로드한 뒤 `127.0.0.1:8443`에서 다시 수신 중인 것을 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 정책 데이터 변경은 수행하지 않았다.
- 브라우저에서 직접 설정 토글, 값 저장과 정책 게시의 종단 간 동작은 수행하지 않았다.
