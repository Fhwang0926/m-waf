# 서버 설치 환경 UI 개선 완료

## 변경 내용

- 운영체제, 웹서버, 실행 환경을 중첩 카드 대신 제목과 비교 행으로 정리했다.
- 지원 OS별 Agent·모듈 범위와 Apache/Nginx 확인 방식을 각 항목에서 바로 확인할 수 있게 했다.
- 일반 서버와 Docker의 Agent 실행 차이를 분리하고 환경 자동 감지 상태를 표시했다.
- 긴 하단 설명은 초기 Agent 설치 범위, 변경하지 않는 설정, 필요 도구 안내로 축약했다.
- 920px 이하에서는 세 영역과 하단 안내를 세로로 배치한다.

## 호환성

- 설치 토큰, 설치 명령, Agent 등록 및 모듈 설치 흐름은 변경하지 않았다.
- 지원 운영체제, 웹서버와 실행 환경의 기존 정보는 유지했다.
- DB와 API는 변경하지 않았다.

## 검증

- 템플릿의 기존 설치 환경 핵심 문구가 유지되는지 확인했다.
- CSS 변수 누락과 변경 파일의 공백 오류를 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 프론트엔드 테스트는 수행하지 않았다.
- 인증된 서버 설치 화면의 브라우저 확인은 수행하지 않았다.
