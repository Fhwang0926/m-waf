# M-WAF Agent 0.3.0

## 변경 내용

- Ubuntu 20.04, 22.04와 26.04 LTS amd64에서 Agent 설치, 등록, 점검과 자기 업데이트를 지원합니다.
- 기존 Ubuntu 18.04, 24.04와 Debian 12 Agent 지원을 유지합니다.
- Ubuntu 18.04, 20.04와 22.04의 배포판 Apache는 공식 ModSecurity 2.9.x 의존성을 사용하는 서명 모듈 DEB로 설치합니다. 해당 버전의 Nginx는 exact-match 서명 모듈만 허용합니다.
- Ubuntu 24.04와 26.04에서는 검증된 배포판 Apache/Nginx 모듈 설치를 지원합니다.

## 호환 범위

- Manager: Ubuntu LTS 지원 매트릭스가 포함된 M-WAF Manager
- Agent OS: Ubuntu 18.04, 20.04, 22.04, 24.04, 26.04 LTS 및 Debian 12
- 배포판 Apache 모듈 OS: Ubuntu 18.04, 20.04, 22.04, 24.04, 26.04 LTS 및 Debian 12
- 배포판 Nginx 모듈 OS: Ubuntu 24.04, 26.04 LTS 및 Debian 12
- Architecture: amd64
- 기존 서버 ID, mTLS 인증서, Agent 설정, state와 spool 형식을 유지합니다.

## 롤백 주의사항

- 자동 롤백은 활성 Manager bundle에 같은 OS와 architecture용 직전 Agent artifact가 포함된 경우에만 동작합니다.
- 새로 추가된 OS의 최초 0.3.0 설치는 이전 M-WAF Agent가 없으므로 초기 rollback artifact가 없습니다.
