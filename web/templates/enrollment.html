설치 구성M-WAF Agent + ModSecurity 통합 모듈

커스텀 빌드 웹서버는 기존 ModSecurity Connector가 로드된 경우 수동 연결 방식을 사용합니다. Apache와 Nginx가 함께 설치되어 있으면 설치 명령에 보호 대상을 지정해야 합니다.

{{.InstallToken}}

고객 웹서버에서 실행

umask 077
printf '%s' '{{.CABase64}}' | base64 -d > /tmp/mwaf-manager-ca.crt

sudo sh /tmp/mwaf-install.sh --manager {{.AgentURL}} --ca /tmp/mwaf-manager-ca.crt --install-token-stdin

명령을 실행한 뒤 토큰 입력란에 위 토큰을 붙여넣으세요. 설치가 끝나면 서버가 자동 등록됩니다.

커스텀 Apache/Nginx 연결 명령

기존 ModSecurity Connector가 이미 로드된 서버에서만 사용합니다.

sudo sh /tmp/mwaf-install.sh \
  --manager {{.AgentURL}} \
  --ca /tmp/mwaf-manager-ca.crt \
  --install-token-stdin \
  --module-install manual \
  --integration external \
  --webserver apache \
  --webserver-bin /opt/hosting/apache/bin/apachectl \
  --integration-config /opt/hosting/apache/conf/extra/mwaf.conf \
  --reload

Nginx는 --webserver nginx와 실제 바이너리·전용 conf 경로를 지정하세요.
