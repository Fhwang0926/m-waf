# 설치 토큰 표시 화면 개선 완료

## 변경 목적

- 설치 명령의 긴 CA 인증서 값 때문에 코드 영역이 과도하게 줄바꿈되는 문제를 수정한다.
- 토큰 관리 표에서 재발급 컨트롤이 행 높이를 불필요하게 키우는 문제를 수정한다.
- 새로 발급하는 기업 설치 토큰을 안전성을 유지하는 범위에서 짧게 만든다.

## 반영 내용

- 설치 명령은 줄바꿈하지 않고 코드 영역 안에서 가로 스크롤되도록 변경해 네 줄 구조를 유지한다.
- 표 안의 재발급 컨트롤에 소형 행 작업 스타일을 적용했다.
- `토큰 상태 및 재발급` 접힘 영역 오른쪽에 열림·닫힘 상태가 바뀌는 드롭다운 화살표를 표시했다.
- 새 설치 토큰의 난수를 256비트에서 128비트로 조정해 전체 길이를 51자에서 30자로 줄였다.
- 목록 식별 접두어는 20자에서 14자로 줄였고, 기존에 발급된 긴 토큰도 짧은 접두어로 표시한다.
- 기존 토큰은 해시 검증 방식이 동일하므로 만료 또는 폐기 전까지 계속 사용할 수 있다.
- DB 스키마와 Agent·Manager API는 변경하지 않았다.

## 확인 내용

- 변경한 Go 파일에 `gofmt`를 적용했다.
- 저장소 전체 변경의 공백 및 패치 형식을 `git diff --check`로 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 직접 데이터 쓰기는 수행하지 않았다.
- 현재 실행 중인 Manager에는 변경 코드가 반영되지 않아 인증 화면의 실제 렌더링은 확인하지 않았다.
