# 기업 보호 정책 상세 탭 분리 완료

## 변경 내용

- 보호 정책 상세의 `개요`, `연결 서버`, `예외·간편 규칙`, `배포 현황`, `변경 이력`을 URL 기반 서버 렌더링 탭으로 분리했다.
- 기존 페이지 내부 이동 링크를 제거하고 선택한 탭 하나만 HTML에 렌더링한다.
- 개요에는 보호 기준 요약과 운영 제어만 표시한다.
- 연결 서버, 배포 현황, 변경 이력 데이터는 해당 탭을 열었을 때만 조회한다.
- 서버 정책 이동과 배포 승인·재시도 후 선택했던 탭으로 돌아오도록 `return_tab`을 보존한다.
- 폼 검증 오류와 개정본 충돌도 작업 중이던 탭에서 다시 표시한다.

## 호환성

- 기존 정책 상세 URL과 POST URL, CSRF, RBAC, 기업 범위 검사는 변경하지 않았다.
- DB 스키마, Agent API, 정책 artifact 형식은 변경하지 않았다.
- JavaScript 없이 새로고침, 뒤로 가기, 링크 복사가 가능한 방식으로 구현했다.

## 검증

- 탭 입력값 정규화, 선택 탭 단독 렌더링, 작업 후 탭 유지 검증 코드를 추가했다.
- Go 소스 형식과 `git diff --check`를 확인했다.
- 저장소 지침에 따라 전체 Go 테스트, 프론트엔드 빌드, 브라우저 실행, DB migration은 수행하지 않았다.
