# M-WAF CRS 적용 준비 버튼 위치 개선 완료

## 작업 목적

`적용 준비` 패널의 주 동작 버튼이 요약 그리드 왼쪽 셀에 연결된 것처럼 보이는 배치를 정리했다.

## 반영 내용

- 기존 `form-actions` 패턴을 재사용해 버튼을 요약 영역과 분리하고 패널 하단 오른쪽에 배치했다.
- 좁은 화면에서는 기존 반응형 규칙에 따라 버튼이 가용 너비를 채우도록 했다.
- 별도 CSS나 동작 변경은 추가하지 않았다.

## 확인 범위

- 실행 중인 Manager 화면과 현재 템플릿에서 기존 왼쪽 정렬 상태를 확인했다.
- 변경분에 대해 `git diff --check`만 수행했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 프론트엔드 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager의 빌드·재시작과 변경 후 실화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
