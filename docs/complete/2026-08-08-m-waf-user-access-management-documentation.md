# M-WAF 사용자 및 접근 권한 관리 문서화

## 완료 범위

- 현재 구현된 `enterprise_user`, `enterprise_admin`, `system_admin` 역할 계층을 문서화했다.
- 역할별 조회·운영·사용자 관리·시스템 관리 권한을 기능 표로 정리했다.
- 기업 범위 강제, 시스템 관리자의 내부 운영 기업과 전역 접근 관계를 기록했다.
- 최초 시스템 관리자, 기업 사용자·관리자 생성과 soft delete 수명주기를 정리했다.
- 자기 계정 보호와 마지막 활성 기업 관리자 보호를 설명했다.
- 비밀번호 저장, 세션 재검증, credential tag, CSRF와 감사 기록 범위를 정리했다.
- 다중 시스템 관리자 운영, 역할 표시 명칭, 내부 운영 기업 구분, 실패 감사 기록과 viewer 역할을 현재 제약 또는 개선 후보로 분리했다.
- README의 운영 안내에서 상세 문서로 연결했다.

## 확인 범위

- 문서 내용은 현재 역할, 세션, 사용자 저장소, 관리자 핸들러, 라우트와 템플릿 구현을 기준으로 대조했다.
- 로컬 DB에서는 역할별 활성 계정 수와 활성 기업 수만 읽기 전용으로 확인했다.
- 코드, DB schema와 실행 상태는 변경하지 않았다.
- 자동 테스트, 프론트엔드 빌드와 브라우저 실행은 수행하지 않았다.
