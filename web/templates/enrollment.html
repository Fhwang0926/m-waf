등록 흐름

  1. 설치기가 서버 OS와 Apache/Nginx 정보를 확인합니다.
  2. 기업 설치 토큰여러 서버가 만료 또는 사용 한도까지 공유할 수 있는 기업 범위 비밀입니다.을 짧은 일회용 등록 세션으로 교환합니다.
  3. Manager에 포함된 Agent와 호환 모듈만 검증해 설치합니다.
  4. 서버별 고유 mTLS 인증서Agent와 Manager가 서로 신원을 확인하는 서버별 인증서입니다.를 발급하고 서버 목록에 자동 등록합니다.

기업 토큰 폐기는 새 설치만 차단합니다. 이미 등록된 Agent는 고유 인증서로 계속 동작합니다.
