# 자동 등록 명령과 커스텀 웹서버 경로 입력 개선

## 반영 내용

- 서버 설치 화면의 `설치 명령 복사`가 기존 관리자 API에서 15분 단기 일회용 등록 토큰을 발급해 명령에 자동으로 포함한다.
- 단기 토큰은 임시 권한 파일로 전달해 설치기 프로세스 인자에 노출하지 않으며, 별도의 터미널 토큰 입력을 제거했다.
- 기업 설치 토큰 원문은 반복 자동화용으로 유지하고 빠른 설치와 용도를 구분했다.
- 설치기에 `--token-file`을 추가해 단기 등록 토큰 파일을 지원한다.
- Apache/Nginx가 `PATH`에 없으면 대화형 설치기가 웹서버 종류와 제어 바이너리 절대 경로를 묻는다.
- 선택한 웹서버가 지원 배포판 패키지 소유가 아니면 external 통합으로 전환하고, 기존 include 범위의 M-WAF 전용 설정 파일 절대 경로를 묻는다.
- 비대화형 설치는 기존처럼 필요한 커스텀 경로 옵션이 없으면 안전하게 중단한다.

## 확인

- 설치기 셸 구문과 Go 템플릿 회귀 검사를 확인했다.
- 실행 중인 Manager에서 자동 토큰 안내와 설치 명령 생성 버튼이 표시되는 것을 확인했다.
- 일회용 토큰 생성 버튼은 DB 쓰기가 발생하므로 화면 확인 중에는 실제로 누르지 않았다.
- DB init, reset 및 직접 데이터 변경은 수행하지 않았다.
- 저장소 지침에 따라 프론트엔드 빌드와 전체 E2E는 수행하지 않았다.
