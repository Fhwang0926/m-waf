# 서버 위험 작업 UI 개선 완료

## 변경 내용

- 위험 작업 화면을 일반 설정 카드에서 별도 제한 운영 영역으로 재구성했다.
- Agent 재시작·중지와 서버 재시작·종료를 명시적인 선택 카드로 구분하고 각 작업의 영향과 복구 방법을 표시했다.
- 위험 명령과 확인 항목은 기본 선택하지 않으며 브라우저 자동 완성을 끄도록 처리했다.
- Agent 중지와 서버 종료를 선택한 경우에만 외부 복구 수단 확인 항목을 표시하고 필수로 검사한다.
- 등록 해제는 접힌 별도 위험 영역으로 분리하고 다음 내용을 먼저 표시한다.
  - mTLS 인증서 폐기
  - 서버·이벤트 이력 보존
  - 재연결 시 신규 등록 필요
- 등록 해제 전 화면에 표시된 서버 이름을 정확히 입력하도록 서버 측 검증을 추가했다.
- 위험 작업 전용 스타일에서 사용한 `--space-5` 간격 토큰을 공통 디자인 토큰에 추가해 카드 여백과 내부 패딩이 무시되던 표시 오류를 수정했다.
- 서비스 영향 확인과 작업 예약 버튼을 데스크톱에서 한 행으로 통합하고 좁은 화면에서만 세로로 배치했다.

## 호환성

- 기존 고정 명령 값, Agent 폴링, 명령 큐, 감사 로그와 등록 해제 경로는 변경하지 않았다.
- 임의 셸 명령 입력은 추가하지 않았다.
- DB 스키마와 Agent API는 변경하지 않았다.

## 검증

- 기본 명령·확인 미선택, 네 가지 고정 명령 표시, 등록 해제 영향 안내와 서버 이름 확인 검증을 통과했다.
- `go test -count=1 ./cmd/mwaf-manager`, `gofmt`, `git diff --check`를 통과했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 프론트엔드 테스트는 수행하지 않았다.
- 실행 중인 Manager의 로그인 화면과 정적 스타일 반영 여부는 확인했지만 인증된 서버 상세 화면은 확인하지 않았다.
- 실제 명령 예약, Agent·서버 중지 또는 등록 해제 같은 운영 상태 변경은 수행하지 않았다.
