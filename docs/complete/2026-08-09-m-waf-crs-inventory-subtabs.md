# CRS 전체 구성 하위 탭 분리

## 변경

- CRS 상세의 `전체 구성`을 `원본 파일`과 `실행 지시문` 하위 탭으로 분리했다.
- 파일 표와 Rule ID 없는 실행 지시문 목록이 한 화면에 동시에 길게 표시되지 않도록 했다.
- 선택한 하위 탭을 `view=files` 또는 `view=directives` URL 쿼리에 유지한다.
- 실행 지시문 원문은 항상 표시하고 펼침 동작과 `고정 commit 원본 열기` 버튼을 제거했다.

## 확인

- 하위 탭 정규화, 선택 콘텐츠 분리와 지시문 상시 표시 회귀 테스트를 추가했다.
- 프론트엔드 빌드·테스트와 DB 변경 작업은 수행하지 않았다.
