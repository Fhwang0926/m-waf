# M-WAF 계정 권한 드롭다운 표시 완료

## 반영 내용

- 상단 계정 버튼에는 사용자 이름만 표시하고 소속·권한은 노출하지 않는다.
- 계정 드롭다운 상단에 `현재 권한` 영역을 추가해 실제 세션 역할을 표시한다.
- 시스템 관리자는 전체 기업·시스템 설정 관리 범위를, 기업 사용자는 소속 기업을 함께 확인할 수 있다.
- 기존 `내 계정`, `로그아웃` 동작과 권한별 메뉴 노출 조건은 변경하지 않았다.
- 기존 관리 콘솔의 색상, 간격과 타이포그래피를 재사용했다.

## 확인 범위

- 공통 navigation 템플릿이 세션의 `RoleLabel`과 `EnterpriseName`을 그대로 사용하는 것을 확인했다.
- 권한 표시 문구를 확인하는 기존 관리자 UI 테스트 조건을 보강했다.
- 접힌 계정 버튼에 역할명과 기업명이 포함되지 않는 조건을 추가했다.
- `git diff --check`로 공백 오류가 없음을 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- 실행 중인 Manager에는 응답했지만 현재 브라우저 세션이 로그인되지 않아 드롭다운의 실제 렌더링은 확인하지 못했다.
- DB 작업, Manager 재시작과 배포는 수행하지 않았다.
