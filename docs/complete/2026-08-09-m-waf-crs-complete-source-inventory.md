# M-WAF CRS 전체 원본 인벤토리·버전 비교 반영 완료

## 작업 목적

Rule ID가 있는 Rule과 일부 Setup만 보이던 CRS 관리 화면을 보완해, 시스템 관리자가 서명된 원본의 전체 구성과 버전 변경 영향을 확인할 수 있게 했다.

## 반영 내용

- CRS 인덱스에 다음 읽기 전용 원본 인벤토리를 추가했다.
  - 전체 파일 경로, 유형, 크기, 줄 수, SHA-256
  - `.data` 파일과 이를 참조하는 Rule ID
  - `SecRuleUpdateTargetById`, `SecMarker`, `SecDefaultAction`, `SecComponentSignature` 등 ID 없는 실행 지시문
  - `crs-setup.conf.example`의 모든 `tx.*` 선언과 시스템 정책 설정 가능 여부
- 신규 CRS 인덱스에는 위 메타데이터가 함께 서명되도록 했다.
- 기존 인덱스는 DB나 서명 파일을 변경하지 않고 검증된 원본 아카이브에서 메타데이터를 메모리상 보완한다.
- 기존 Rule·Setup DB 테이블과 스키마는 변경하지 않았다.
- CRS 상세에 `전체 구성` 탭을 추가했다.
  - 모든 배포 포함 파일과 해시를 조회한다.
  - Manager가 보유한 검증 원본 내용을 새 탭에서 직접 확인한다.
  - ID 없는 지시문의 원문과 고정 commit 위치를 확인한다.
- `CRS Setup` 탭은 원본 전체 키와 M-WAF 관리 대상 키를 구분해 표시한다.
- 변경 비교 API와 화면에 원본 Setup, 전체 파일, `.data`, 기타 지시문 차이를 추가했다.
- 시스템 정책 마이그레이션 2단계에도 같은 전체 원본 변경 건수를 표시한다.
- 기존 `/api/v1/open-source-policies`의 `items`, Rule API와 Agent 배포 형식은 유지했다.

## 실데이터 확인

로컬에 보존된 OWASP CRS LTS 4.25.1 서명 아카이브로 새 인덱스를 생성해 다음을 확인했다.

- ID 기반 Rule: 627개
- Rule `.conf`: 27개
- 전체 배포 포함 파일: 52개
- `.data`: 21개
- 원본 Setup 키: 31개
- 시스템 정책 관리 대상 Setup: 17개
- ID 없는 실행 지시문: 91개

## 확인 범위

- `internal/crsindex` 단위 테스트를 통과했다.
- CRS 상세 탭·템플릿·전체 원본 diff 회귀 테스트를 통과했다.
- `gofmt`와 `git diff --check`를 통과했다.
- 실행 중인 Manager의 로그인된 화면에서 LTS 4.25.1의 Setup `원본 31개 · 관리 17개` 표시를 확인했다.
- 같은 화면의 `전체 구성` 탭에서 파일 52개, Rule 627개, Rule 파일 27개, `.data` 21개, 기타 지시문 91개가 표시되는 것을 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 프론트엔드 자동 테스트는 수행하지 않았다.
- DB init/reset, 스키마 마이그레이션과 직접 데이터 변경은 수행하지 않았다.
- 브라우저 보안 확장 기능이 새 raw API 탭을 차단해 `내용 보기` 새 탭의 원문 렌더링은 확인하지 못했다.
- 실제 Agent에 새 정책을 게시하거나 배포하지 않았다.
