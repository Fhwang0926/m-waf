# 서버 시스템 정보 카드 UI 개선 완료

## 반영 내용

- 서버 상세 상태 탭의 시스템 정보 영역을 카드형 레이아웃으로 정리했다.
- 운영체제는 공식 배포판 이미지가 강조되는 서버 플랫폼 카드로 분리했다.
- CPU, 메모리, Agent 연결, 정책 현황, 보호 준비 항목에 일관된 선형 아이콘을 추가했다.
- 5개 정보를 3열 기준선에 맞춰 배치하고, 하단의 보호 준비 카드는 두 열을 사용해 카드 경계가 어긋나지 않도록 했다.
- Agent·정책·보호 준비 상태에 따라 아이콘 색상이 기존 상태 색상과 연결되도록 했다.
- 긴 Agent 버전은 한 줄에서 생략 표시하고 전체 값은 제목으로 확인할 수 있게 했다.
- 태블릿과 모바일에서는 2열, 1열로 자연스럽게 전환되도록 반응형 배치를 조정했다.

## 검증 범위

- 기존 서버 상태 정보와 문구는 유지했다.
- 서버 상세 템플릿 회귀 테스트의 확인 항목을 갱신했다.
- 지침에 따라 Go 테스트, 프론트엔드 빌드와 실행 화면 확인은 수행하지 않았다.
