# 감사 기록 요청 ID 표시 제거 완료

## 변경 목적

- 감사 기록 목록에서 운영 판단에 불필요한 내부 요청 ID 정보를 노출하지 않는다.

## 반영 내용

- 감사 기록의 대상 셀에서 `요청 ID` 펼침 영역을 제거했다.
- 목록 상단의 내부 요청 ID 안내 문구를 제거하고 건수와 페이지 정보만 유지했다.
- 감사 데이터 저장, 조회 구조와 API는 변경하지 않았다.

## 확인 내용

- 저장소 전체 변경의 공백 및 패치 형식을 `git diff --check`로 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 직접 데이터 쓰기는 수행하지 않았다.
- 실행 중인 Manager에는 변경 코드가 반영되지 않아 인증 화면의 실제 렌더링은 확인하지 않았다.
