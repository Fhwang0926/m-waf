# 관리자 화면 중복 이동 버튼 정리 완료

## 완료 범위

- 전체 관리자 템플릿의 페이지 상단 작업 영역을 사이드 메뉴 목적지와 대조했다.
- 10개 화면에서 사이드 메뉴와 같은 위치로 이동하던 12개 버튼을 제거했다.
  - CRS 소스: `정책 버전 보기`
  - 정책 버전: `CRS 소스`, `기업 적용 현황`
  - 서버 그룹: `기업 정책`
  - 보호 서버: `서버 그룹`, `설치 및 등록`
  - 관리자 감사 로그: `로그 보존 설정`
  - 사용자 수정: `사용자 목록`
  - 그룹 상세, 기업 정책 상세, 서버 상세: `목록`
  - CRS 소스 상세: `CRS 소스 목록`
- 생성, 편집, 동기화, 저장, 배포 같은 실제 작업 버튼은 유지했다.
- 입력 화면의 취소·닫기, 필터 초기화, 오류·빈 화면의 복구 동작과 상세 조건으로 이동하는 운영 링크는 현재 작업 흐름에 필요하므로 유지했다.

## 검증

- 모든 `page-head` 선언을 다시 검색해 남은 버튼이 실제 작업, 상태 표시 또는 작성 흐름의 취소 동작임을 확인했다.
- `git diff --check`를 통과했다.
- 로컬 `https://127.0.0.1:8443` Manager가 실행 중이 아니어서 실제 화면 응답은 확인하지 못했다.
- 프로젝트 규칙에 따라 프론트엔드 빌드와 브라우저 조작 테스트는 실행하지 않았다.
