# 관리자 화면 KST 시간 기준 통일 완료

## 변경 목적

- 관리자 화면에 표시되는 시각과 사용자가 입력하는 만료 시각을 한국 표준시로 통일한다.
- 저장·정렬·Agent 통신에 사용하는 UTC 기준은 유지해 기존 데이터 및 API 호환성을 보존한다.

## 반영 내용

- Go 템플릿에서 공통으로 사용하는 KST 포맷 함수를 추가하고, 관리자 화면의 날짜·시각 표시를 KST로 변경했다.
- 대시보드, 이벤트 실시간 목록과 상세, 마지막 갱신 시각 등 JavaScript로 갱신되는 시간도 `Asia/Seoul` 기준으로 표시한다.
- IP 신뢰 규칙과 시스템 정책 긴급 우회의 `datetime-local` 입력을 KST로 안내하고 KST로 해석한 뒤 UTC로 변환해 저장한다.
- 서버 상태 안내와 CRS 동기화 재시도 시각 등 백엔드에서 만드는 사용자용 문구도 KST로 변경했다.
- 감사 기록의 개별 조회 결과를 변환하던 처리를 제거하고 공통 템플릿 포맷을 사용하도록 정리했다.
- DB 세션, DB 저장값, 기간 검색, 만료 비교, 이벤트 수신, Agent·Manager API의 UTC 기준은 변경하지 않았다.

## 확인 내용

- 변경한 Go 파일에 `gofmt`를 적용했다.
- 관리자 템플릿의 사람용 직접 시간 포맷과 UTC 표기가 남아 있지 않은지 확인했다.
- `datetime-local` 입력 경로가 KST 파서를 사용하고 저장 전에 UTC로 변환되는지 확인했다.
- 저장소 전체 변경의 공백 및 패치 형식을 `git diff --check`로 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 직접 데이터 쓰기는 수행하지 않았다.
- 현재 실행 중인 Manager에는 변경 코드가 반영되지 않아 인증 화면의 실제 렌더링은 확인하지 않았다.
