# 보호 서버 시스템 정보 요약 완료

## 변경 내용

- 보호 서버 상세의 상태 탭을 하나의 시스템 정보 위젯으로 통합했다.
- 운영체제 로고와 버전, 아키텍처, CPU 논리 코어 수, 전체 메모리, Agent 연결, 보호 정책 현황, 보호 준비 상태를 함께 표시한다.
- Ubuntu는 기존 브랜드 이미지를 사용하고, 다른 운영체제는 중립 OS 표식을 사용한다.
- 상태 탭에서는 페이지 제목의 온라인 배지를 숨겨 동일 상태가 중복 표시되지 않도록 했다. 다른 탭에서는 현재 연결 배지를 유지한다.
- Agent가 heartbeat inventory에 `cpu_core_count`와 `memory_total_bytes`를 포함해 Manager의 기존 `inventory_json`에 저장하도록 확장했다.
- 기존 Agent가 새 필드를 보내지 않으면 CPU와 메모리를 `수집 대기`로 표시한다.

## 호환성

- 기존 heartbeat API와 JSON 구조에 선택 필드만 추가했으며 DB 스키마는 변경하지 않았다.
- 기존 Agent, 기존 저장 데이터, 등록 직후 아직 heartbeat가 없는 서버도 그대로 표시할 수 있다.
- CPU는 Agent가 사용할 수 있는 논리 코어 수, 메모리는 Linux `/proc/meminfo`의 전체 메모리를 기준으로 한다.

## 검증

- 메모리 수집값과 상태 탭 시스템 정보 렌더링 검증 코드를 추가했다.
- Go 소스 형식과 `git diff --check`를 확인했다.
- 저장소 지침에 따라 전체 Go 테스트, 프론트엔드 빌드, 브라우저 실행, DB 작업은 수행하지 않았다.
