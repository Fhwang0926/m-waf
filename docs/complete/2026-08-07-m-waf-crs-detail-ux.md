# CRS 소스 상세 UX 개선 완료

## 완료 범위

- 상단 정책 생성 버튼 문구를 짧게 정리하고 한 줄로 유지했다.
- 상세 탭을 화면 상단에 유지해 긴 Rule 목록에서도 다른 구역으로 바로 이동할 수 있게 했다.
- 출처·무결성 정보를 저장소, 태그·버전, 고정 commit, Rule 구성으로 구분해 표시했다.
- 고정 commit 복사 기능과 해시·내부 식별자 접기 영역을 추가했다.
- 시스템 정책 비교와 패키지 호환성 수치를 구분된 요약 셀로 표시했다.
- Rule 검색을 통합 검색, Rule ID, 파일의 기본 조건과 tag, PL, phase, 위험도의 고급 조건으로 분리했다.
- 적용된 검색 조건을 필터 배지로 표시하고 고급 조건 사용 시 해당 영역을 자동으로 펼친다.
- 가로로 길었던 5열 Rule 표를 요약 목록으로 변경했다.
  - Rule ID, PL, 위험도, phase와 파일 위치는 목록에서 바로 확인한다.
  - 연산자, 대상 변수, tag, 원본 SecRule과 GitHub 고정 링크는 필요한 Rule만 펼쳐 확인한다.
- CRS Setup 표를 반응형 설정 카드로 변경해 기본값, 허용 범위·값과 설명을 함께 읽을 수 있게 했다.
- 1080px, 920px, 760px 구간에서 출처 정보, Rule 항목과 Setup 항목이 순차적으로 한 열로 전환되도록 구성했다.

## 검증

- `git diff --check`를 통과했다.
- 기존 조회 파라미터와 서버 응답 구조는 변경하지 않았다.
- 로컬 Manager가 실행 중이 아니어서 로그인된 실제 화면은 확인하지 못했다.
- 프로젝트 규칙에 따라 프론트엔드 빌드와 브라우저 조작 테스트는 실행하지 않았다.
