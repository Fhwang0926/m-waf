동작 방식

  1. 설치기가 서버 OS와 Apache/Nginx 정보를 확인합니다.
  2. 기업 토큰을 짧은 일회용 등록 세션으로 교환합니다.
  3. Manager에 포함된 Agent와 호환 모듈만 검증해 설치합니다.
  4. 서버별 고유 mTLS 인증서를 발급하고 서버 목록에 자동 등록합니다.

기업 토큰 폐기는 새 설치만 차단합니다. 이미 등록된 Agent는 고유 인증서로 계속 동작합니다.
