# M-WAF 보호 정책 기업 범위 전환 완료

## 작업 목적

기업 운영의 `보호 정책` 화면에서 시스템 관리자가 여러 기업 정책을 한 목록으로 조회·추가할 수 있던 구조를 한 기업 관점으로 전환했다.

## 반영 내용

- 시스템 관리자는 보호 정책 화면에 들어오면 먼저 운영 기업을 선택하도록 했다.
- 기업 선택을 검색 조건이 아닌 필수 운영 범위로 분리했다.
- 선택 전에는 정책 목록과 추가 동작을 표시하지 않는다.
- 선택 후에는 해당 기업 정책만 조회하고 상단 현재 범위에도 기업명을 표시한다.
- 정책 검색의 기업 조건과 목록의 기업 열을 제거했다.
- 기존 검색 조건과 시스템 정책 사용 현황을 유지한 채 기업을 선택할 수 있고, 검색 초기화·정책 추가·취소 동작에서도 선택한 기업 범위를 유지한다.
- 보호 정책 추가 화면의 서버·그룹·기업 기본 대상도 선택한 기업으로 제한했다.
- 정책 생성 요청에서도 선택 기업과 실제 적용 대상의 기업 범위가 일치하는지 확인한다.
- 기업 사용자와 기업 관리자는 기존처럼 자기 기업 범위만 사용한다.
- 시스템 정책, 라우트, 데이터 모델과 DB는 변경하지 않았다.

## 확인 범위

- 기업 필터, 세션 권한 범위, 정책 목록·추가 화면의 데이터 흐름을 정적으로 확인했다.
- Go 포맷과 `git diff --check`를 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager의 빌드·재시작과 변경 후 실화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
