# 설치 환경 공식 브랜드 아이콘 적용 완료

## 변경 목적

- 서버 설치 화면의 지원 환경을 긴 문구보다 공식 프로젝트 이미지를 중심으로 빠르게 구분할 수 있게 한다.

## 반영 내용

- 설치 환경 표를 운영체제와 웹서버 두 카드로 정리했다.
- 중복 설명이던 `설치 구성 / Agent + 통합 모듈` 시각 카드를 제거했다.
- Ubuntu, Apache HTTP Server, Nginx가 공식 배포처에서 제공하는 이미지 원본을 로컬 정적 자산으로 포함했다.
- 로고만으로 전달되지 않는 Ubuntu 버전, CPU 아키텍처, 선택·결합 관계는 짧은 보조 문구로 유지했다.
- 원본 색상을 바꾸지 않고 어두운 화면에서도 식별되도록 각 로고에 맞는 배경 영역을 적용했다.
- 작은 화면에서는 카드가 한 열로 배치되도록 기존 반응형 구간에 연결했다.

## 확인 내용

- 추가한 이미지의 파일 형식과 크기를 확인했다.
- 템플릿에서 모든 이미지에 대체 텍스트를 지정했다.
- 저장소 전체 변경의 공백 및 패치 형식을 `git diff --check`로 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 직접 데이터 쓰기는 수행하지 않았다.
- 실행 중인 Manager에 변경 코드가 반영되기 전이므로 인증 화면의 실제 렌더링은 확인하지 않았다.
