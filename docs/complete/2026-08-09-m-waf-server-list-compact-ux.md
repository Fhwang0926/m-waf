# M-WAF 보호 서버 목록 중복 UI 정리 완료

## 작업 목적

보호 서버 화면의 중복 제목과 서버 설치 버튼을 정리하고 기본 검색 동작을 한 행에서 완료할 수 있도록 개선했다.

## 반영 내용

- 페이지 제목 `보호 서버`를 유지하고 목록 패널의 중복 `서버 목록` 제목을 제거했다.
- 상단 `전체 N대`와 중복되는 목록 패널의 `N대 표시` 배지를 제거했다.
- 목록 패널에 단독으로 떠 있던 안내 문구를 페이지 소개 문구에 통합하고 패널은 검색 영역부터 시작하도록 정리했다.
- 등록된 서버가 없을 때는 빈 상태의 `서버 설치` 버튼만 표시한다.
- 등록된 서버가 있을 때는 페이지 상단의 `서버 설치` 버튼만 표시한다.
- 필터가 지정되어 있어도 등록 서버가 0대이면 빈 상태에서 설치 동작을 유지한다.
- 서버 검색, 연결 상태, 조건 초기화와 검색 버튼을 데스크톱에서 한 행으로 배치했다.
- 공통 중간 화면 반응형 규칙이 검색 버튼을 다음 줄로 내리지 않도록 서버 검색 행의 열 위치를 고정했다.
- 작은 화면에서는 기존 반응형 구조에 따라 검색 항목을 세로로 배치한다.
- 기존 서버 목록 URL, 필터 파라미터와 설치 경로는 변경하지 않았다.

## 확인 범위

- 서버 유무와 필터 상태별 버튼 조건, 템플릿 구조와 CSS 선택자를 정적으로 확인했다.
- `git diff --check`를 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager의 재시작과 변경 후 로그인 화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
