# 감사 기록 KST 및 10건 페이지 표시 완료

## 변경 목적

- 감사 기록 시간을 운영자가 사용하는 한국 표준시로 표시한다.
- 한 페이지에 표시되는 기록을 10건으로 줄여 목록 가독성을 높인다.

## 반영 내용

- DB의 UTC 저장 방식과 기간 검색 기준은 유지했다.
- 조회된 감사 기록 시간만 UTC+9 고정 오프셋의 KST로 변환해 표시한다.
- 감사 기록 페이지 크기를 100건에서 10건으로 변경했다.
- 조회 한도, 다음 페이지 판정과 페이지 오프셋에 동일한 10건 기준을 적용했다.

## 확인 내용

- 변경한 Go 파일에 `gofmt`를 적용했다.
- 저장소 전체 변경의 공백 및 패치 형식을 `git diff --check`로 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 직접 데이터 쓰기는 수행하지 않았다.
- 실행 중인 Manager에는 변경 코드가 반영되지 않아 인증 화면의 실제 렌더링은 확인하지 않았다.
