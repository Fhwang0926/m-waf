# M-WAF 서버 패키지 화면 UI 개선 완료

## 변경 내용

- 패키지 화면을 실제 상세 작업 카드와 동일하게 `Agent 준비 → 웹서버 연동`의 두 단계로 정리했다. 웹서버 확인, 모듈 설치와 설정 연동은 두 번째 단계에서 현재 상태에 따라 이어서 안내한다.
- Agent 현재 버전, Manager 제공 버전과 실제 변경 범위를 한 영역에서 확인하도록 정리했다.
- 구형 Agent의 1회 전환은 복사 버튼을 우선 제공하고 긴 명령은 `직접 실행 명령 보기` 안으로 접었다.
- 현재 서버와 호환되는 서명 Agent가 없으면 실행할 수 없는 전환 명령을 노출하지 않고 준비 필요 상태를 표시한다.
- 감지된 웹서버 정보와 설치 방식 선택을 좌우 영역으로 구분했다.
- `unknown` 모듈 버전은 설치된 버전처럼 표시하지 않고 `모듈 미설치`로 표현한다.
- 기존 고객 설정 파일을 자동으로 수정하지 않으며 Agent 업데이트가 모듈·정책·웹서버 설정을 변경하지 않는다는 안내를 유지했다.
- 좁은 화면에서는 단계, Agent 정보와 설치 계획이 한 열로 배치되도록 반응형 스타일을 추가했다.
- Agent 업데이트 예약 중에는 1단계를 진행 상태로 표시하고, 완료 상태와 충돌하던 문구를 `업데이트 예약됨`으로 통일했다.
- 예약 상태 안내의 중첩 박스를 제거하고 다음 웹서버 연동 단계는 Agent 업데이트 완료 전까지 간결한 대기 상태로 표시한다.
- 긴 Agent 개발 버전은 한 줄로 생략 표시하며 전체 값은 기존 제목 속성으로 확인할 수 있게 했다.
- Agent 롤백은 현재 버전 artifact의 `rollback_id`만으로 노출하지 않고, 현재 Agent 버전과 일치하는 Agent 단독 배포가 `APPLIED`로 확인된 경우에만 제공하도록 제한했다.
- 롤백 버튼에 실제 대상 버전을 표시하고, 롤백할 이력이 없을 때는 불필요한 Agent 재시작 확인 체크박스도 숨겼다.
- 롤백 POST 요청에서도 같은 성공 업그레이드 조건을 다시 검증해 화면을 우회한 요청을 차단했다.

## 확인 결과

- Manager 템플릿 및 권한 관련 단위 테스트를 통과했다.
- 실행 중인 Manager의 인증된 서버 패키지 화면에서 새 단계 구조와 상태 문구를 확인했다.
- 현재 Manager bundle에 호환 Agent가 없는 실제 상태에서 전환 명령과 복사 버튼이 숨겨지고 `전환 패키지 준비 필요`가 표시되는 것을 확인했다.
- 실제 Inventory의 `module_version=unknown`이 `모듈 미설치`로 표시되는 것을 확인했다.
- `git diff --check`를 통과했다.
- Agent 단독 배포의 `APPLIED` 판정과 롤백 버튼 표시 조건에 대한 회귀 테스트를 추가했다.

## 수행하지 않은 작업

- 프론트엔드 빌드는 수행하지 않았다.
- Agent 전환, 모듈 설치 또는 웹서버 reload 버튼을 실행하지 않았다.
- DB migration, init, reset은 수행하지 않았다.
