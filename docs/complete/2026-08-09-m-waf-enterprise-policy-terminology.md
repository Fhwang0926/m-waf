# M-WAF 기업 정책 용어 통일 완료

## 작업 목적

기업 운영 메뉴와 화면에서 같은 정책 기능을 `보호`, `보호 설정`, `IP 관리`로 다르게 부르던 문제를 정리했다.

## 반영 내용

- 기업 운영 사이드바 구역명을 `정책`으로 변경했다.
- 메뉴와 페이지 제목을 `보호 정책`, `IP 정책`으로 통일했다.
- 보호 정책 목록·추가·변경·상세·배포 안내와 서버·이벤트 연결 문구를 같은 용어로 정리했다.
- IP 정책 화면에서 보호 정책을 참조하는 안내 문구를 통일했다.
- 사이드바 권한 노출 검증 문자열을 새 메뉴명에 맞췄다.
- 시스템 정책 작성 과정에서 모드·민감도 같은 실제 구성값을 뜻하는 `보호 설정` 문구는 유지했다.
- 라우트, 데이터 모델, 저장·배포 동작은 변경하지 않았다.

## 확인 범위

- 기업 정책 UI의 기존 용어 사용 위치를 정적 검색했다.
- 변경분에 대해 `git diff --check`를 수행했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager의 빌드·재시작과 변경 후 실화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
