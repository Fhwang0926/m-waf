# 웹서버 정책 적용 방식 UI 문구 개선 완료

## 변경 내용

- `표준 웹서버 제어`를 `자동 설정 검사·재적용 (권장)`으로 변경했다.
- `고객 Hook 사용`을 `사용자 지정 실행 파일 사용 (고급)`으로 변경했다.
- 기본 방식은 감지된 Apache/Nginx 명령으로 설정 검사와 안전한 재적용을 수행한다고 안내한다.
- 사용자 지정 방식은 호스팅사 제어 프로그램이나 별도 supervisor가 있는 경우에만 선택하도록 설명을 추가했다.
- 사용자 지정 실행 파일 경로는 고급 방식을 선택한 경우에만 자동으로 펼쳐 표시한다.
- 설치 후 정책 재적용 방식 변경 화면과 제어 이력의 표시 문구도 같은 용어로 통일했다.

## 호환성

- 내부 `standard`, `hooks` 값과 고정 실행 파일 경로는 변경하지 않았다.
- 자유 셸 명령 입력은 추가하지 않았다.
- Agent 명령, 설치 계획, DB와 API 형식은 변경하지 않았다.

## 검증

- 변경된 UI 문구, 고정 경로와 내부 명령 값이 유지되는지 정적으로 확인했다.
- 변경 파일의 공백 오류를 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 테스트는 수행하지 않았다.
- 실제 웹서버 설정 검사, 재적용과 사용자 지정 실행 파일 호출은 수행하지 않았다.
