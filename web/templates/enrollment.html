2. 고객 웹 서버에서 실행

기존 ModSecurity Connector를 패키지 없이 연결

Connector가 이미 로드된 커스텀 웹서버에서만 사용합니다. Manager는 Connector 바이너리를 설치하거나 교체하지 않고 Agent와 전용 include만 설치합니다.

sudo sh /tmp/mwaf-install.sh \
  --manager {{.AgentURL}} \
  --ca /tmp/mwaf-manager-ca.crt \
  --install-token-stdin \
  --module-install manual \
  --integration external \
  --webserver apache \
  --webserver-bin /opt/hosting/apache/bin/apachectl \
  --integration-config /opt/hosting/apache/conf/extra/mwaf.conf \
  --reload

Nginx는 --webserver nginx, 해당 nginx 절대 경로와 http 컨텍스트에 포함되는 전용 conf 경로를 지정하세요.
