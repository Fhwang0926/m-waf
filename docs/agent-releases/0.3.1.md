# M-WAF Agent 0.3.1

## 변경 내용

- Docker/OCI supervisor를 셸 기본 기능으로 분리해 터미널에서 설치해도 현재 디렉터리에 `nohup.out`을 만들지 않습니다.
- 서명과 SHA-256 검증을 마친 로컬 DEB 설치에서 APT가 접근할 수 없는 root 전용 디렉터리를 `_apt`로 다시 읽지 않도록 명시했습니다.
- Agent DEB에 실제 `Installed-Size`를 기록해 설치 전 디스크 사용량을 올바르게 표시합니다.

## 호환 범위

- Manager: Ubuntu LTS 지원 매트릭스와 Agent 단독 업데이트를 지원하는 M-WAF Manager
- Agent OS: Ubuntu 18.04, 20.04, 22.04, 24.04, 26.04 LTS 및 Debian 12
- Architecture: amd64
- 기존 서버 ID, mTLS 인증서, 설정, state와 spool 형식을 유지합니다.

## 운영 참고

- 기존 `nohup.out`은 자동 삭제하지 않습니다. 실행 중인 Agent가 해당 파일을 사용하지 않는 것을 확인한 후 운영자가 정리합니다.
- 컨테이너를 recreate해도 Agent 바이너리를 유지하려면 서명 DEB가 포함된 파생 이미지와 기존 영속 볼륨 구성이 필요합니다.
