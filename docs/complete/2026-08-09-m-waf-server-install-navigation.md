# M-WAF 서버 설치 메뉴 분리 완료

## 작업 목적

보호 서버 목록에서 버튼으로만 진입하던 설치 기능을 `서버` 섹션의 독립 메뉴로 분리했다.

## 반영 내용

- `서버` 섹션의 `보호 서버` 아래에 `서버 설치` 메뉴를 추가했다.
- 기존 `/enrollments/new` 설치 페이지와 `enrollments` 활성 상태를 그대로 재사용했다.
- 서버 설치 화면에서는 `서버 설치` 메뉴만 활성화되고 `보호 서버`는 활성화되지 않도록 구분했다.
- 보호 서버와 서버 설치 화면의 상위 위치 문구를 `기업 운영 · 서버`로 통일했다.
- 보호 서버 화면의 설치 진입 버튼도 `서버 설치`로 통일했다.
- 라우트, 권한, 설치 토큰, Agent 설치 동작은 변경하지 않았다.

## 확인 범위

- 기존 설치 라우트, 설치 화면과 활성 메뉴 키를 정적으로 확인했다.
- 사이드바 권한·활성 상태 검증 문자열을 새 메뉴에 맞췄다.
- 변경분에 대해 `git diff --check`를 수행했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager의 빌드·재시작과 변경 후 실화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
