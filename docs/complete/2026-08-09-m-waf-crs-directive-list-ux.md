# M-WAF CRS 실행 지시문 목록 UX 개선 완료

## 작업 목적

`전체 구성` 탭의 `ID 없는 실행 지시문` 목록에서 원문 열기 동작이 항목 전체 너비를 차지해 입력 필드처럼 보이고, 지시문명·파일·줄 위치의 관계가 분산되어 보이는 문제를 정리했다.

## 반영 내용

- 지시문명과 참조 Rule은 왼쪽, 파일명과 줄 위치는 오른쪽의 한 줄 메타 정보로 통합했다.
- `원본 지시문 보기`를 내용 너비에 맞는 접기/펼치기 동작으로 축소하고 방향 표시를 추가했다.
- 펼친 상태에서는 문구가 `원본 지시문 닫기`로 바뀌도록 했다.
- 좁은 화면에서는 파일명과 줄 위치가 지시문명 아래로 배치되도록 했다.
- 구역 설명을 Rule ID가 없는 지시문의 역할이 드러나도록 정리했다.
- Rule Set 목록의 공용 레이아웃은 변경하지 않고 실행 지시문 구역 전용 스타일만 추가했다.

## 확인 범위

- 실행 중인 Manager의 로그인된 화면에서 기존 원문 열기 영역이 항목 전체 687px 너비를 차지하는 것을 확인했다.
- 템플릿과 CSS 변경분에 대해 `git diff --check`만 수행했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 프론트엔드 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager는 템플릿과 정적 자산이 포함된 바이너리이므로 변경 후 화면 재확인은 빌드·재시작 전에는 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
