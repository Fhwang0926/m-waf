# 기업 목록 내부 ID 표시 제거

- `/enterprises` 기업 목록에서 운영에 필요하지 않은 `내부 ID 보기`와 UUID 표시를 제거했다.
- 기업 목록의 별도 `관리` 열과 삭제·운영 종료 입력 UI를 제거했다.
- 기업명 링크뿐 아니라 목록 행을 선택해도 기업 상세 화면으로 이동한다. 공통 `data-row-href` 동작을 재사용했다.
- 삭제 또는 운영 종료는 기업 상세의 `기업 관리` 위험 작업 영역에서만 제공한다.
- 연결 데이터가 없으면 영구 삭제, 연결 이력이 있으면 운영 종료로 처리하는 기존 서버 규칙과 기업명 확인 절차를 유지했다.
- 보호 기업과 이미 운영 종료된 기업은 상세 화면에서 상태만 안내하고 실행 버튼을 표시하지 않는다.
- 운영 종료 성공과 처리 오류는 해당 기업 상세 화면에서 확인한다. 영구 삭제 성공은 대상 상세가 사라지므로 기업 목록으로 이동한다.
- API, DB와 기업 생명주기 데이터 구조는 변경하지 않았다.
- 관련 Go 파일에 `gofmt`를 적용하고 템플릿을 포함한 `git diff --check`를 확인했다.
- 현재 개발 Manager가 변경된 템플릿을 로드한 뒤 `127.0.0.1:8443`에서 다시 수신 중인 것을 확인했다.
- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
