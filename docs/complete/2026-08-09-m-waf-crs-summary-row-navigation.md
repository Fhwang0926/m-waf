# CRS 버전 목록 요약·상세 동선 개선

## 완료 내용

- CRS 버전 목록을 버전·채널, Rule·Setup 인덱스, 시스템 정책 연결의 3개 요약 열로 정리했다.
- 목록의 `GitHub 검증`, `정책 생성 준비`, `작업` 열을 제거했다.
- 행의 비어 있는 영역을 클릭하면 해당 CRS 상세 화면으로 이동하도록 연결했다.
- 버전명은 실제 링크로 유지해 JavaScript가 동작하지 않아도 키보드로 상세 화면에 진입할 수 있게 했다.
- GitHub 검증 결과와 검증값 복사 기능은 CRS 상세 화면의 출처·무결성 영역으로 이동했다.
- 시스템 정책 보기·반영 작업은 기존 CRS 상세 화면의 상단 액션으로 유지했다.

## 호환성

- 기존 CRS 목록·상세 URL, 검색 조건, 페이지 처리, 복사 기능과 시스템 정책 액션 URL은 변경하지 않았다.
- DB, API, 정책 모델과 상세 화면의 호환 패키지 정보는 변경하지 않았다.

## 검증 범위

- Go 템플릿 파싱, JavaScript 문법, CSS 괄호, `git diff --check`를 정적으로 확인했다.
- 저장소 지침에 따라 프론트엔드 빌드, 자동 테스트, 브라우저 실행, DB migration은 수행하지 않는다.
