# M-WAF 기업 식별 헤더 개선 완료

## 작업 목적

로그인한 사용자의 소속 기업, 역할 권한, 현재 조회 범위를 화면에서 구분해 확인할 수 있도록 관리 콘솔 공통 헤더를 개선했습니다.

## 반영 내용

- 기업 사용자와 기업 관리자는 사이드바의 `M-WAF` 아래에서 `기업명 관리 콘솔`을 확인할 수 있습니다.
- 시스템 관리자는 사이드바에서 `시스템 관리 콘솔`로 표시됩니다.
- 우측 계정 영역에는 표시 이름 아래에 `기업명 · 역할`을 함께 표시합니다.
- 시스템 관리자가 운영 현황, 서버, 이벤트, 정책, 그룹, 사용자 화면에서 기업 필터를 선택하면 상단 `현재 범위`가 선택한 기업명으로 표시됩니다.
- 서버, 그룹, 기업 정책과 사용자 상세 화면에서는 해당 자원이 속한 기업명을 `현재 범위`로 표시합니다.
- 기업명이 긴 경우 기존 헤더 너비를 넘기지 않고 말줄임 처리합니다.

## 유지한 동작

- 세션에 이미 포함된 기업명과 기존 기업 목록을 재사용했습니다.
- 사용자 권한, 테넌트 범위, DB 스키마와 조회 조건은 변경하지 않았습니다.
- 시스템 관리자의 전체 조회 상태는 계속 `전체 기업`으로 표시됩니다.

## 확인 범위

- 공통 템플릿과 범위 라벨 데이터 전달 경로를 정적 확인했습니다.
- 개발 Manager가 변경을 감지해 새 프로세스로 정상 재기동되고 `127.0.0.1:8443`의 로그인 화면에 응답하는 것을 확인했습니다.
- 확인용 브라우저에 로그인 세션이 없어 권한별 공통 헤더의 실제 렌더링은 확인하지 못했습니다.
- 프로젝트 지침에 따라 프론트엔드 빌드와 테스트는 수행하지 않았습니다.
