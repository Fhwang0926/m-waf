# M-WAF 시스템 정책 확인 버튼 활성화 개선 완료

## 작업 목적

시스템 정책 작성 단계에서 Rule 변경 영향을 확인하지 않아도 다음 단계로 이동할 수 있던 문제를 개선했다.

## 반영 내용

- upstream Rule·공통 예외 영향 확인 체크박스를 필수 입력으로 변경했다.
- 확인 전에는 `보호 설정` 버튼을 비활성화하고 체크 즉시 활성화한다.
- CRS 채널 전환 확인이 표시되는 경우 두 항목을 모두 확인해야 진행할 수 있다.
- 기존 전체 WAF 우회가 있는 정책은 유지 확인 전에 `검증 및 게시` 단계로 이동할 수 없게 했다.
- JavaScript를 우회한 직접 요청도 Manager 검증에서 `confirm_changed_rules` 누락으로 차단한다.
- 기존 CSRF, 정책 검증 digest, 게시 확인 및 권한 검증은 변경하지 않았다.

## 확인 범위

- Go 수정 파일에 `gofmt`를 적용했다.
- JavaScript 구문, 템플릿 구분자 균형과 `git diff --check`를 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 자동 테스트, 전체 Go 빌드와 프론트엔드 빌드는 수행하지 않았다.
- Manager 재빌드·재시작 및 브라우저 확인은 수행하지 않았다.
- DB 조회·변경, migration, init, reset은 수행하지 않았다.
