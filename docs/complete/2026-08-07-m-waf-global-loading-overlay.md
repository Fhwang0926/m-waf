# 관리자 화면 전역 로딩 오버레이 완료

## 완료 범위

- 공통 `app.js`에 전역 작업 상태 관리자를 추가했다.
- 정상 유효성 검사를 통과한 GET 폼에는 `페이지를 불러오는 중입니다.`, POST 폼에는 `작업 요청을 처리하는 중입니다.` 오버레이를 표시한다.
- 같은 Manager 안에서 다른 화면이나 검색 조건으로 이동하는 링크와 수동 새로고침에도 페이지 로딩 상태를 표시한다.
- 작업 중에는 modal dialog로 화면 입력을 차단해 중복 클릭과 중복 제출을 막는다. 제출 버튼의 `name`/`value`는 서버 요청에 유지한다.
- 10초 이상 응답이 없으면 같은 작업을 다시 요청하지 않도록 지연 안내 문구를 표시한다.
- 브라우저 뒤로 가기와 bfcache 복원 시 제출 상태와 오버레이를 초기화한다.
- 정책 검증 API는 전역 검증 상태를 표시하고 성공·오류 모두 `finally`에서 해제한다.
- 이벤트 상세 패널의 기존 부분 로딩, 대시보드·이벤트 30초 polling, 개발 서버 상태 확인은 전역 오버레이에서 제외했다.
- 로그인과 최초 시스템 관리자 설정 화면도 공통 JavaScript를 불러와 같은 제출 피드백을 제공한다.
- 기존 작업 패널 위에서도 가려지지 않도록 일반 fixed 요소가 아닌 최상위 modal dialog를 사용했다.
