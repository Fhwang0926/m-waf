# M-WAF CRS 기본 버전·시스템 오버라이드 운영 모델 반영 완료

## 작업 목적

시스템 관리자가 별도의 M-WAF 정책 버전을 관리하지 않고, `OWASP CRS 기본 버전 + 시스템 오버라이드`만 선택·검토·게시하도록 운영 흐름을 단순화했다.

## 반영 내용

- 시스템 관리 메뉴와 화면의 관리 대상을 `CRS 버전`과 `시스템 오버라이드`로 정리했다.
- CRS 원본은 읽기 전용으로 유지하고 공통 보호 설정, 예외, 추가 Rule만 오버라이드하도록 설명과 작성 흐름을 변경했다.
- 같은 CRS 버전을 유지한 상태에서도 시스템 오버라이드만 다시 검토·게시할 수 있게 했다.
- 관리자 목록에서는 같은 CRS에서 생성된 내부 배포 식별자를 여러 버전처럼 표시하지 않고 최신 오버라이드 한 건으로 합쳐 표시한다.
- 기업 정책의 기준 선택과 적용 현황은 M-WAF 내부 버전 대신 OWASP CRS 버전으로 표시한다.
- 게시 완료, 검증 오류, 롤백 오류와 배포 영향 안내도 CRS 기준과 시스템 오버라이드 용어로 통일했다.

## 내부 호환성

- Agent에는 계속 CRS 원본과 시스템 오버라이드를 결합한 불변 artifact를 전달한다.
- 롤백·동시성 검증에 필요한 내부 식별자는 그대로 유지하지만 관리자 화면의 별도 관리 버전으로 노출하지 않는다.
- DB 스키마, 기존 정책 데이터, Agent polling 경로와 프로토콜은 변경하지 않았다.

## 확인 범위

- 변경한 Go 파일에 `gofmt`를 적용했다.
- 사용자 화면에서 내부 시스템 정책 버전이 관리 항목으로 노출되지 않는지 정적으로 검색했다.
- `git diff --check`로 공백 오류가 없음을 확인했다.
- 실행 중인 Manager가 `127.0.0.1:8443`에서 응답하고 로그인 화면으로 연결되는 것을 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- 현재 브라우저 세션에 관리자 로그인이 없어 로그인 후 CRS·오버라이드 화면의 실제 렌더링은 확인하지 못했다.
- DB init/reset, 스키마 마이그레이션과 데이터 변경은 수행하지 않았다.
- Manager 재시작과 배포는 수행하지 않았다.
