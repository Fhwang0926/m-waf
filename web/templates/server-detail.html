최후 수단 · 신규 등록

신원 파일이 손상된 경우에만 완전 제거합니다

/var/lib/mwaf-agent/server-id, agent.crt 또는 agent.key가 없거나 손상되어 등록 유지 재설치를 할 수 없을 때만 사용합니다.

  1. {{if .CanOperate}}위험 작업에서 기존 서버 등록을 해제합니다.{{else}}기업 관리자에게 기존 서버 등록 해제를 요청합니다.{{end}}
  2. sudo /usr/sbin/mwaf-uninstall --dry-run으로 제거 범위를 먼저 확인합니다.
  3. 영향을 승인한 경우에만 sudo /usr/sbin/mwaf-uninstall --purge를 실행합니다.
  4. 서버 설치에서 새 설치 명령을 복사해 Agent를 신규 등록합니다.

신규 등록은 새 서버 ID를 만들고 완료 전까지 M-WAF 보호가 중단됩니다. Apache/Nginx 자체는 제거하지 않지만 기존 서버 이력과 새 서버는 자동으로 합쳐지지 않습니다. 제거 도구가 없으면 파일을 임의로 삭제하지 말고 시스템 관리자에게 요청하세요.
