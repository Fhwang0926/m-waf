# M-WAF Agent 0.3.2

## 변경 내용

- systemd 없는 컨테이너에서 PID 1의 stdout이 터미널이면 Agent 로그를 해당 터미널에 연결하지 않습니다.
- 대화형 PID 1 셸에서는 Agent 로그를 `/var/log/mwaf-agent/agent.log`에 기록합니다.
- Apache/Nginx 같은 실제 컨테이너 프로세스가 PID 1인 일반 서비스 컨테이너에서는 기존 stdout/stderr 로깅을 유지합니다.

## 호환 범위

- Manager: Ubuntu LTS 지원 매트릭스와 Agent 단독 업데이트를 지원하는 M-WAF Manager
- Agent OS: Ubuntu 18.04, 20.04, 22.04, 24.04, 26.04 LTS 및 Debian 12
- Architecture: amd64
- 기존 서버 ID, mTLS 인증서, 설정, state와 spool 형식을 유지합니다.

## 운영 참고

- systemd 환경에서는 기존과 같이 `journalctl -u mwaf-agent`로 로그를 확인합니다.
- 대화형 PID 1 셸을 사용하는 컨테이너에서는 `tail -f /var/log/mwaf-agent/agent.log`로 로그를 확인합니다.
- 실제 컨테이너 서비스의 stdout으로 연결된 경우에는 기존 컨테이너 로그 명령을 사용합니다.
