# M-WAF Agent 0.2.1

## 변경 내용

- Docker/OCI 컨테이너에서 Agent 패키지 교체 후 supervisor를 완전히 중지하고 다시 시작해 새 바이너리가 즉시 실행되도록 수정했습니다.
- 레거시 Agent 전환 확인 중 새 heartbeat를 기다리는 HTTP 409 응답을 반복 출력하지 않도록 정리했습니다.

## 호환 범위

- Manager: Agent 단독 배포 scope를 지원하는 M-WAF Manager
- OS: Ubuntu 18.04, Ubuntu 24.04, Debian 12
- Architecture: amd64
- 기존 서버 ID, mTLS 인증서, Agent 설정, state와 spool 형식을 유지합니다.

## 기존 0.2.0 컨테이너 조치

- 파일만 0.2.0으로 교체되고 Manager 화면이 이전 버전으로 남아 있다면 `/usr/sbin/mwaf-agent-service stop` 후 `start`를 한 번 실행합니다.
- Manager가 새 heartbeat를 확인한 뒤 0.2.1 bundle에서 등록 유지 Agent 재설치를 다시 실행합니다.
