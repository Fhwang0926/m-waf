# M-WAF 설치 명령 빠른 안내 UX 개선

## 목적

- 긴 보안 설치 명령을 처음부터 노출하지 않고, 기업 운영자가 복사와 실행 순서를 바로 이해할 수 있게 한다.
- 설치 토큰을 URL이나 명령 인자로 포함하지 않는 기존 보안 방식을 유지한다.

## 반영 내용

- 신규 토큰 화면과 기존 활성 토큰 화면에 동일한 빠른 설치 영역을 적용했다.
- 기본 화면은 `설치 명령 복사`와 실행 후 토큰을 입력하라는 한 문장만 표시한다.
- 단순한 작업을 마법사처럼 보이게 하던 3개 단계 카드를 제거했다.
- 전체 설치 명령과 커스텀 Apache/Nginx 연결 명령은 필요한 경우에만 펼쳐 보도록 접었다.
- 명령 펼침 항목에 방향 표시를 추가해 열고 닫을 수 있는 영역임을 명확히 했다.
- 저장한 토큰이 없는 경우 빠른 설치 영역에서 토큰 재발급 목록을 즉시 열 수 있게 했다.
- 클립보드 복사에 실패하면 전체 명령 영역을 자동으로 열어 수동 복사할 수 있게 했다.
- 펼친 명령은 좁은 화면에서 페이지를 가로로 밀어내지 않도록 줄바꿈한다.

## 보안 및 호환성

- 기존 CA 인증서 검증과 `curl --fail --cacert` 흐름을 유지했다.
- 설치 토큰은 복사 대상 명령에 포함하지 않고 `--install-token-stdin`으로 별도 입력한다.
- `curl -k`, URL query token, local/session storage를 추가하지 않았다.
- 설치 API, 설치 스크립트, DB 스키마는 변경하지 않았다.
- JavaScript를 사용할 수 없어도 전체 명령을 펼쳐 수동 복사할 수 있다.

## 정적 검증

- Go 템플릿의 간결한 설치 안내, 단계 카드 제거, 접힌 명령, `--install-token-stdin`, 토큰 비포함 회귀 검증을 추가했다.
- 템플릿 제어 블록 수와 `git diff --check`를 확인했다.
- 현재 Manager가 `127.0.0.1:8443`에서 실행 중임을 확인했다. 최종 화면 재확인 시 브라우저 세션이 로그인 화면으로 전환되어 인증 후 렌더링은 확인하지 못했다.
- 저장소 지침에 따라 전체 Go 테스트, 프론트엔드 빌드, DB migration은 실행하지 않았다.
