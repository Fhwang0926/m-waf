# M-WAF Agent 0.2.0

## 변경 내용

- Agent가 `agent-self-update-v1`, `agent-local-rollback-v1` capability를 보고합니다.
- Manager가 웹서버 모듈과 정책을 변경하지 않는 Agent 단독 업데이트를 예약할 수 있습니다.
- 새 Agent가 제한 시간 안에 heartbeat를 확인하지 못하면 독립 updater가 직전 서명 DEB로 자동 복구합니다.
- 기존 Agent는 등록 토큰 없이 기존 서버 ID와 mTLS 인증서를 사용하는 `--upgrade-agent` 1회 전환을 지원합니다.

## 호환 범위

- Manager: Agent 단독 배포 scope를 지원하는 M-WAF Manager
- OS: Ubuntu 18.04, Ubuntu 24.04, Debian 12
- Architecture: amd64
- 기존 Agent 설정, 인증서, state와 spool 형식을 유지합니다.

## 롤백 주의사항

- 자동 롤백은 활성 Manager bundle에 같은 OS와 architecture용 직전 Agent artifact가 포함된 경우에 동작합니다.
- 컨테이너를 원본 이미지에서 recreate하면 writable layer에 설치한 Agent가 사라질 수 있으므로 Agent DEB가 포함된 파생 이미지를 사용해야 합니다.
