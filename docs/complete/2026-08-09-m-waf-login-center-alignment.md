# M-WAF 로그인 화면 중심 정렬 개선 완료

## 작업 목적

로그인 카드가 화면 중앙에 배치되어 있어도 제목 영역과 우측의 작은 로그인 버튼 때문에 한쪽으로 치우쳐 보이던 시각적 불균형을 정리했다.

## 반영 내용

- 로그인 카드의 M-WAF 브랜드, 화면 구분, 제목과 소개 문구를 중앙 정렬했다.
- 로그인 버튼을 입력창과 같은 전체 너비로 확장해 주요 동작의 중심축을 맞췄다.
- 로그인 화면 전용 클래스를 사용해 최초 시스템 관리자 설정 화면과 다른 공통 폼에는 영향을 주지 않도록 범위를 제한했다.
- 기존 로그인 요청 경로, 입력 필드와 인증 동작은 변경하지 않았다.

## 확인 범위

- 현재 실행 중인 `https://localhost:8443/login`에서 변경 전 카드가 화면 정중앙에 배치된 것을 확인했다.
- 카드 내부에서 로그인 버튼이 우측 정렬되어 시각적 중심이 어긋나는 원인을 확인했다.
- 변경된 템플릿 구조와 CSS 선택자의 적용 범위를 정적으로 확인했다.
- `git diff --check`를 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 정적 리소스가 실행 파일에 포함되는 구조이므로 실행 중인 Manager를 재시작하지 않았고, 변경 후 화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
