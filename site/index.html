MODSECURITY CONTROL PLANE

기존 웹서버는 그대로.
WAF 운영은 한곳에서.

M-WAF는 호스팅사가 여러 Apache·Nginx 서버의 ModSecurity 정책과 보안 이벤트를 한 대의 Manager에서 관리할 수 있게 하는 경량 웹방화벽입니다.

BUILT FOR OPERATORS

새 WAF를 만드는 대신,
검증된 구성요소를 연결합니다.

01

기존 웹서버 유지

고객의 Apache 또는 Nginx 프로세스와 80/443 트래픽 경로를 바꾸지 않습니다.

02

설치는 정확히 두 개

공통 Agent 하나와 해당 웹서버용 ModSecurity 모듈 패키지 하나만 설치합니다.

03

Upstream 우선

ModSecurity와 OWASP CRS를 그대로 사용합니다. Nginx는 libmodsecurity를 요청 처리 단계에 연결하는 배포판 연동 모듈을 함께 사용합니다.

ARCHITECTURE

차단은 서버에서,
관리는 중앙에서.

Manager 장애가 발생해도 웹 요청은 Manager를 거치지 않습니다. 각 서버는 마지막으로 검증된 정책으로 계속 보호됩니다.

MVP CAPABILITIES

운영에 필요한 핵심만.

별도 메시지 브로커나 검색 클러스터 없이 Go, MariaDB, Docker Compose로 단순하게 구성했습니다.

01

정확한 패키지 선택

OS, CPU, 웹서버 버전과 정규화된 빌드 해시가 모두 일치하는 Agent·모듈만 Manager가 제공합니다.

02

서명된 정책 배포

Ed25519 서명과 SHA-256을 검증하고 설정 검사 성공 후에만 Apache 또는 Nginx를 reload합니다.

03

자동 롤백

정책 검증이나 reload가 실패하면 이전 정책 파일을 복원하고 다시 검증합니다.

04

안전한 Agent 통신

일회용 등록 토큰과 Agent별 인증서를 사용하며 모든 운영 통신은 mTLS로 보호합니다.

05

감사 로그 수집

ModSecurity JSON 이벤트를 디스크에 spool하고 최대 500건씩 멱등 batch로 전송합니다.

06

한 번에 배포

Manager와 MariaDB는 Compose로, 고객 서버 패키지는 동일 Manager 이미지에서 내려받습니다.
