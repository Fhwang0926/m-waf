# 기업 설치 토큰 자동 생성 완료

## 변경 목적

- 기업 등록 직후 별도 버튼 없이 기업 설치 토큰을 준비한다.
- 기존 기업도 서버 설치 화면을 열 때 활성 토큰이 없으면 자동으로 복구한다.
- Manager DB에는 토큰 원문을 저장하지 않고 생성 직후 한 번만 표시하는 기존 보안 구조를 유지한다.

## 반영 내용

- 기업 등록 완료 후 새 기업이 선택된 서버 설치 화면으로 이동하도록 연결했다.
- 서버 설치 화면의 GET 요청에서 활성 토큰이 없으면 폐기 전까지 사용하는 기업 설치 토큰을 자동 생성한다.
- 기업 행을 잠근 트랜잭션 안에서 활성 토큰 확인과 생성을 처리해 동시 화면 요청의 중복 발급을 방지했다.
- 자동 생성된 토큰 원문과 설치 명령을 같은 화면에 한 번 표시한다.
- 기존 활성 토큰이 있으면 새로 만들지 않고 현재 접두어와 사용 상태를 표시한다.
- 기존 생성 버튼은 제거하고, 토큰 원문을 분실한 경우의 작업을 `재발급`으로 정리했다. 재발급 시 기존 토큰을 폐기한 뒤 새 토큰을 자동 생성한다.
- DB 스키마, Agent 등록 프로토콜과 기존 만료형 토큰 API는 변경하지 않았다.

## 확인 내용

- 변경한 Go 파일에 `gofmt`를 적용했다.
- 저장소 전체 변경의 공백 및 패치 형식을 `git diff --check`로 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 자동 테스트는 실행하지 않았다.
- DB init, reset, migration과 직접 데이터 쓰기는 수행하지 않았다.
- 현재 실행 중인 Manager에는 변경 바이너리가 반영되지 않아 자동 생성 화면과 실제 토큰 발급은 확인하지 않았다.
