# 등록 해제 서버 영구 삭제 완료

## 변경 내용

- 등록 해제된 서버의 상세 화면 상단에 `서버 영구 삭제` 버튼과 `위험 작업` 탭을 표시한다.
- 등록 해제 상태에서는 서비스 제어와 등록 해제 작업 대신 `서버 영구 삭제`만 표시한다.
- 전용 위험 작업 화면에서는 중복 경고와 펼침 UI를 제거하고 삭제 범위, 확인 입력과 실행 버튼을 하나의 카드에 배치한다.
- 영구 삭제 전에 화면에 표시된 서버 이름 재입력과 복구 불가 확인을 모두 요구한다.
- 백엔드에서 기업 범위와 등록 해제 상태를 트랜잭션 안에서 다시 확인한다.
- 서버에 연결된 정책 배포, 패키지 배포, 제어 명령, 보안 이벤트·인시던트와 상태 데이터를 함께 삭제한 뒤 서버 행을 삭제한다.
- 영구 삭제를 수행한 관리자, 서버 ID와 서버 이름은 기존 관리자 감사 로그에 보존한다.

## 권한과 안전장치

- 등록 해제를 수행할 수 있는 기업 운영자 이상만 서버 영구 삭제를 수행할 수 있다.
- 활성 서버는 영구 삭제 API를 직접 호출해도 삭제되지 않는다.
- 다른 기업의 서버는 현재 기업 범위에서 조회하거나 삭제할 수 없다.
- 일부 의존 데이터 삭제에 실패하면 전체 트랜잭션을 되돌려 서버가 불완전하게 삭제되지 않도록 했다.

## 정적 확인

- 서버 외래키를 사용하는 모든 현재 테이블과 삭제 순서를 비교했다.
- 수정한 Go 파일에 `gofmt`를 적용했다.
- `git diff --check`에서 공백 오류가 없음을 확인했다.

## 수행하지 않은 검증

- 저장소 지침에 따라 프론트엔드 빌드와 테스트는 수행하지 않았다.
- DB 데이터 변경 금지 지침에 따라 실제 서버 영구 삭제 요청은 실행하지 않았다.
- 인증된 브라우저에서 영구 삭제 화면과 동작은 실행하지 않았다.
