# M-WAF 대시보드 마이그레이션 복구

## 현상

- 시스템 관리자 대시보드가 `운영 현황을 불러올 수 없습니다`와 HTTP 500을 표시했다.
- 서버와 이벤트가 없는 초기 개발 DB에서도 동일하게 발생했다.

## 원인

- DB에는 `010_crs_policy_storage.sql`이 적용됐다고 기록되어 있었다.
- 현재 대시보드 정책 현황 조회가 사용하는 `policy_migration_impacts` 테이블은 존재하지 않았다.
- `010`이 처음 적용된 뒤 해당 테이블 정의가 같은 마이그레이션 파일에 추가되어, 이미 `010`을 기록한 DB에서는 추가 구문이 다시 실행되지 않았다.

## 변경

- 전진형 `011_policy_migration_impacts.sql`을 추가했다.
- 신규 DB에서는 `010`에서 이미 생성된 테이블을 `IF NOT EXISTS`로 그대로 유지한다.
- 기존 영향 DB에서는 다음 Manager 시작 시 누락된 테이블만 생성한다.
- 기존 데이터 초기화나 reset 구문은 포함하지 않았다.

## 확인

- 현재 개발 DB의 마이그레이션 기록과 실제 테이블 목록을 읽기 전용으로 비교했다.
- `010`의 다른 CRS 및 구조화 정책 테이블은 존재하고 `policy_migration_impacts`만 누락된 것을 확인했다.
- 실제 DB migration 적용, DB 초기화/reset, 전체 Go 테스트, 프론트엔드 빌드, 브라우저 실행은 수행하지 않았다.
