# 보호 서버 상세 탭 분리 완료

## 변경 내용

- 보호 서버 상세의 `상태`, `환경`, `정책`, `패키지`, `제어 이력`, `위험 작업`을 URL 기반 탭으로 분리했다.
- 기존 페이지 내부 이동 링크를 제거하고 선택한 탭 하나만 HTML에 렌더링한다.
- 정책, 설치 후보, 패키지 롤백 가능 여부, 제어 이력은 해당 탭을 열었을 때만 조회한다.
- 설치, 패키지 변경, 웹서버 제어 방식 변경, 위험 명령 예약 후 작업하던 탭으로 돌아오도록 처리했다.
- 등록 해제되었거나 권한이 없는 서버에서 위험 작업 탭을 직접 요청하면 상태 탭을 표시한다.

## 호환성

- 기존 서버 상세 URL은 상태 탭의 기본 URL로 유지했다.
- 기존 POST URL, CSRF, RBAC, 기업 범위 검사는 변경하지 않았다.
- DB 스키마, Agent API, 정책 및 패키지 형식은 변경하지 않았다.
- JavaScript 없이 새로고침, 뒤로 가기, 링크 복사가 가능한 방식으로 구현했다.

## 검증

- 탭 입력값 정규화와 선택 탭 단독 렌더링 검증 코드를 추가했다.
- Go 소스 형식과 `git diff --check`를 확인했다.
- 저장소 지침에 따라 전체 Go 테스트, 프론트엔드 빌드, 브라우저 실행, DB 작업은 수행하지 않았다.
