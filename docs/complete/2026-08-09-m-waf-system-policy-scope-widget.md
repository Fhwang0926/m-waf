# M-WAF 시스템 정책 적용 현황 위젯 통합 완료

## 작업 목적

현재 시스템 정책의 `적용 범위` 요약과 별도 `기업 적용 현황` 버튼이 같은 정보를 반복하던 구성을 하나의 위젯으로 통합했다.

## 반영 내용

- 현재 시스템 정책 요약의 `적용 범위` 항목을 `기업 적용 현황` 위젯으로 변경했다.
- 기업 수와 서버 수를 유지하고 위젯 전체를 기업 정책 현황 이동 영역으로 만들었다.
- 마우스와 키보드 포커스 상태에서 이동 가능한 영역임을 구분하도록 기존 색상 체계 안에서 강조했다.
- 위젯 아래의 중복 `기업 적용 현황` 버튼을 제거했다.
- 기존 기업 정책 현황 URL과 데이터 조회 방식은 변경하지 않았다.

## 확인 범위

- 템플릿의 링크와 조건 구조, CSS 선택자 및 중복 버튼 제거 여부를 정적으로 확인했다.
- `git diff --check`를 확인했다.

## 수행하지 않은 검증

- 프로젝트 지침에 따라 프론트엔드 빌드와 자동 테스트는 수행하지 않았다.
- 실행 중인 Manager의 재시작과 변경 후 로그인 화면 확인은 수행하지 않았다.
- DB 조회·변경, init, reset, 스키마 마이그레이션은 수행하지 않았다.
