# M-WAF 기업 운영·시스템 관리 권한 분리 완료

## 반영 내용

- 시스템 관리자 계정의 실제 역할과 현재 메뉴 영역의 유효 역할을 요청 단위로 분리했다.
- 기업 운영 HTML/API에서는 시스템 관리자를 소속 기업의 기업 관리자로 제한하고, 시스템 관리 HTML/API에서만 전 기업 시스템 관리자 권한을 적용했다.
- 시스템 관리자는 두 메뉴 섹션을 함께 볼 수 있지만 기업 운영 화면에서는 기업 관리자 역할과 소속 기업 범위가 표시된다.
- 기업 운영 화면의 기업 선택과 다른 기업 ID 요청은 소속 기업 범위로 강제된다.
- 기업 상세의 서버·정책·그룹은 읽기 전용으로 변경하고 운영 화면으로 이동하는 링크를 제거했다.
- 시스템 관리 전용 기업 사용자 관리 경로를 추가하고 기업 관리자·기업 사용자만 생성·수정·비활성화·삭제할 수 있게 했다.
- 시스템 정책의 기업 적용 현황을 시스템 관리 내부 읽기 전용 화면으로 분리했다.
- 시스템 관리자가 기업 운영 권한으로 수행한 감사 대상에는 콘솔 영역, 유효 역할과 소속 기업을 함께 기록한다.

## 확인 내용

- 시스템 관리자 기업 운영 역할 투영과 소속 기업 범위 테스트 통과
- 기업 관리자의 시스템 관리 접근 차단 테스트 통과
- 다른 `enterprise_id` 요청 무시 및 소속 기업 강제 테스트 통과
- 기업 운영·시스템 관리 메뉴 동시 표시와 영역별 역할 표시 테스트 통과
- 시스템 전용 기업 사용자 관리 경로와 읽기 전용 시스템 정책 적용 현황 템플릿 테스트 통과
- `git diff --check` 통과
- 실행 중인 개발 Manager가 소스 변경 후 자동 재빌드된 것을 확인했고 로그인 화면 응답을 확인했다.

## 수행하지 않았거나 별도 확인이 필요한 내용

- 프론트엔드 빌드는 수행하지 않았다.
- DB init, reset, 스키마 마이그레이션은 수행하지 않았다.
- 브라우저에 인증된 Manager 세션이 없어 로그인 후 실제 권한별 화면 전환은 확인하지 못했다.
- 전체 `internal/manager` 테스트는 기존 이벤트 페이지네이션 테스트 2건(`TestPaginateEventRecordsForward`, `TestPaginateEventRecordsBackward`)이 실패했다. 이번 권한 분리 대상 테스트는 모두 통과했다.
